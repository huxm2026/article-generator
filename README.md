# DeepSeek-R1-Distill-Qwen-1.5B 自然语言生成预研项目

# 项目简介

本项目是一个面向端侧设备的自然语言生成预研项目，旨在有限硬件条件下验证基于 DeepSeek R1 Distill Qwen 1.5B​ 模型的英文文章自动生成可行性，
为后续更大规模模型的落地与迁移提供技术铺垫与实证数据。

项目不追求生产级完整能力，而是聚焦于以下核心目标：

    验证低算力环境下模型的加载与推理表现
    探索自然语言生成在普通电脑上的可用边界
    积累模型量化、推理优化、部署调优的实践经验
    为未来向更大模型迁移或场景落地提供数据与结论支撑
    技术路线
    

# 本项目采用"网络大模型辅助 + 本地小模型生成 + 多级语义校验"的分阶段生成流程，具体如下：

## 第一阶段：主题关键词筛选与题目拟定

利用更大规模的网络语言模型，对基础词表（COCA 高频词表）进行分类，从中筛选出与主题相关的关键词，并据此生成故事题目。

## 第二阶段：本地模型词句扩展与文章生成

运行本地蒸馏模型 DeepSeek R1 Distill Qwen 1.5B，针对已拟定的题目关键词，借助 GloVe 6B 词向量库​ 查找语义一致的词语，逐步将词语扩展为词句片段，最终生成完整文章。

## 第三阶段：语义锚点与质量校验

由于本地模型生成的文章可能存在语义不完整、结构杂乱、文体不确定（说明文/论述文/记叙文）等问题，本阶段执行以下操作：

借助网络大模型，将生成的词句片段组织为一两句故事开头或结尾，作为语义锚点；
使用 Sentence Transformer​ 句子语义稠密向量库，计算生成文章与语义锚点的相似度，判断是否符合语义要求；不合格的文章直接丢弃并重新生成，直至产出合格文章。

## 第四阶段：后处理与筛选

利用语言工具中的文章评价标准和相关算法，对生成文章进行最终筛选，符合标准的保留，不符合标准的丢弃。

# 核心依赖与工具

    组件	                                 主要作用
    DeepSeek-R1-Distill-Qwen-1.5B​	     本地文本生成核心模型
    SpaCy（en_core）​	                 分词、词性标注、命名实体识别、依存句法分析、
                                           词形还原、语义相似度计算、文本分类与信息提取
    NLTK（nltk_data）​	                 分词、词性标注、词干提取与词形还原、命名实体
                                           识别、依存句法分析、文本分类
    GloVe 6B​	                         提供 50/100/200/300 维预训练词向量，覆盖约 40 
                                           万英文词汇，建模词语间语义关系
    Sentence Transformers​	             将句子映射为稠密向量，实现语义相似度计算、语义
                                           搜索、文本聚类、问答、去重与微调

# 评估指标

每篇文章的评估结果保存在对应 analysis/ 目录下，评价维度包括但不限于：

    语义连贯性（基于 Sentence Transformer 语义相似度）
    文本结构完整性
    语法正确性（基于 SpaCy/NLTK 句法分析）
    词表覆盖度（基于 COCA 频度范围）
    文体一致性
    

# 项目定位

本项目属于预研性质的探索项目，主要目标是在受限硬件条件下把前期技术风险摸清楚，把可行路径走出来。项目采用 MIT 开源协议，欢迎在此基础上进行二次开发与扩展。
